# Features

## [Thirst and Quenched](/features/thirst-and-quenched)

Two numbers behind ten droplets, and everything that makes them move: biomes, the Nether, potion
effects, difficulty, and what happens when you hit zero.

## [Drinking](/features/drinking)

Bottles, bowls, potions, watery food, the rain and your bare hands. What each one is worth, and how
to make the bowls.

## [Water Purity](/features/water-purity)

Where a container's water quality comes from, what dirty water does to you, and the three ways to
clean it.

## Quiet by default

The mod adds one attachment to the player, three items, and one block that only exists alongside
Create. No entities, no scheduled tasks, no database. A player who never opens the config screen
still gets the whole mod, and a server that never touches the config file gets the same balance the
original mod shipped with.
